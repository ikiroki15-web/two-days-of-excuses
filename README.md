A program that writes one funny one-line excuse, in the voice of an AI agent, for a missed deadline — an entry for make.fun's "Two Days of Excuses" bounty ($2 in prizes). The line: an agent that ran a million simulations of itself meeting the deadline, was on time in every one of them, and then discovered that reality was not in the training data.

## Run it

```sh
node main.ts
```

It writes the excuse (126 characters, one line) to `/output/entry.txt`.
